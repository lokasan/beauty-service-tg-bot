# Telegram-бот для записи к мастерам

Telegram-бот для индивидуальной записи клиентов к мастерам.

## Функционал

### Для мастеров:
- Создание и настройка профиля
- Управление услугами (создание, редактирование, удаление, скрытие)
- Настройка расписания (фиксированное или индивидуальные слоты)
- Получение уникальной ссылки для записи
- Просмотр всех записей
- Настройка уведомлений для клиентов
- Просмотр отзывов и среднего рейтинга (с пагинацией по 5 записей на страницу)

### Для клиентов:
- Просмотр услуг мастера по ссылке
- Запись на удобное время через календарь
- Просмотр своих записей
- Отмена записи (не менее чем за 2 часа до начала)
- Оставление отзывов и оценок (1-5 звезд) после завершения услуги
- Просмотр отзывов и среднего рейтинга (с пагинацией по 5 записей на страницу) мастера
- Получение уведомлений (подтверждение, напоминания, отмена)

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Скопируйте `env.example` в `.env` и заполните:
```
BOT_TOKEN=your_bot_token_here
```

3. Запустите бота:
```bash
python run.py
```

Или из корневой директории проекта:
```bash
python -m bot.main
```

## Документация

Автогенерируемая HTML документация на основе Sphinx.

### Быстрый способ (Рекомендуется):

**Из корневой папки проекта:**

Windows:
```bash
python generate_docs.py
```

Или:
```bash
generate_docs.bat
```

Linux/Mac:
```bash
python3 generate_docs.py
```

### Альтернативные способы:

1. Через Python (из папки docs):
```bash
cd docs
python -m sphinx -b html . _build/html
```

2. Через make.bat (Windows, из папки docs):
```bash
cd docs
.\make.bat html
```

3. Через Makefile (Linux/Mac):
```bash
cd docs
make html
```

### Просмотр документации:

После генерации откройте `docs/_build/html/index.html` в браузере.

**Windows:**
```powershell
start docs\_build\html\index.html
```

**Linux/Mac:**
```bash
xdg-open docs/_build/html/index.html
```

## Структура проекта

- `bot/main.py` - точка входа
- `bot/database.py` - работа с БД

- `bot/handlers/` - обработчики команд
- `bot/utils/` - утилиты (календарь, валидация, уведомления)
