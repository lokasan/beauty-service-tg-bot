Примеры использования
=====================

Примеры кода и сценарии использования.

Создание обработчика команды
-----------------------------

Пример простого обработчика команды:

.. code-block:: python

   from telegram import Update
   from telegram.ext import ContextTypes
   
   async def my_command(update: Update, context: ContextTypes.DEFAULT_TYPE):
       """Обработчик команды /mycommand"""
       await update.message.reply_text("Привет! Это моя команда.")

Регистрация в main.py:

.. code-block:: python

   application.add_handler(CommandHandler("mycommand", my_command))

Создание callback обработчика
------------------------------

Пример обработчика callback query:

.. code-block:: python

   async def my_callback(update: Update, context: ContextTypes.DEFAULT_TYPE):
       """Обработчик callback query"""
       query = update.callback_query
       await query.answer()
       
       # Извлекаем данные из callback_data
       data = query.data  # например, "action_value"
       
       # Редактируем сообщение
       await query.edit_message_text("Результат действия")

Работа с базой данных
---------------------

Пример получения данных из БД:

.. code-block:: python

   from bot.handlers.common import get_db_from_context
   from bot.models import User
   
   async def get_user(update: Update, context: ContextTypes.DEFAULT_TYPE):
       db = get_db_from_context(context)
       user_data = update.effective_user
       
       # Получаем пользователя
       user = db.query(User).filter(
           User.telegram_id == user_data.id
       ).first()
       
       if not user:
           # Создаем пользователя
           user = User(
               telegram_id=user_data.id,
               username=user_data.username,
               full_name=user_data.full_name
           )
           db.add(user)
           db.commit()

Создание inline клавиатуры
---------------------------

Пример создания inline клавиатуры:

.. code-block:: python

   from telegram import InlineKeyboardButton, InlineKeyboardMarkup
   
   keyboard = [
       [InlineKeyboardButton("Кнопка 1", callback_data="action_1")],
       [InlineKeyboardButton("Кнопка 2", callback_data="action_2")],
       [InlineKeyboardButton("Назад", callback_data="back")]
   ]
   reply_markup = InlineKeyboardMarkup(keyboard)
   
   await update.message.reply_text(
       "Выберите действие:",
       reply_markup=reply_markup
   )

Сценарии использования
----------------------

Сценарий 1: Мастер создает услугу
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Мастер нажимает "📋 Мои услуги"
2. Выбирает "➕ Добавить услугу"
3. Вводит название (проверка на запрещенные категории)
4. Вводит описание
5. Вводит цену (валидация)
6. Вводит длительность (валидация)
7. Услуга создана и отображается в списке

Сценарий 2: Клиент записывается
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Клиент переходит по ссылке мастера
2. Видит список услуг мастера
3. Выбирает услугу
4. Выбирает дату из календаря
5. Выбирает время из доступных слотов
6. Предоставляет контакт (телефон)
7. Подтверждает запись
8. Получает уведомление о подтверждении

Сценарий 2.1: Просмотр записей клиента
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Клиент открывает "📅 Мои записи"
2. Видит список записей (по 5 на странице):
   - Будущие записи (для отмены)
   - Завершенные записи за последние 30 дней (для отзывов)
3. Для каждой записи видит:
   - Статус (⏳ ожидание, ✅ подтверждено, ✔️ завершено)
   - Услугу, мастера, стоимость
   - Кнопки "❌ Отменить" (для будущих записей)
   - Кнопку "⭐ Оставить отзыв" (для завершенных записей без отзыва)
4. Переходит между страницами через кнопки "◀️ Предыдущая" и "Следующая ▶️"

Сценарий 3: Мастер настраивает расписание
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Мастер нажимает "⚙️ Настройки"
2. Выбирает "📅 Расписание"
3. Выбирает "📅 Общее расписание"
4. Настраивает часы работы по дням недели
5. Или выбирает календарь для индивидуальных дней
6. Устанавливает выходные дни или индивидуальное расписание

Сценарий 4: Отмена записи клиентом
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Клиент открывает "📅 Мои записи"
2. Видит список своих записей
3. Для каждой доступной записи видит кнопку "❌ Отменить"
4. Нажимает "Отменить" для нужной записи
5. Система проверяет:
   - Запись принадлежит клиенту
   - Запись не отменена и не завершена
   - До начала записи не менее 2 часов
6. Статус записи меняется на "Отменена"
7. Мастер получает уведомление об отмене
8. Слот освобождается и становится доступным для новой записи

Сценарий 5: Оплата услуги
~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Мастер завершает запись
2. Нажимает "💳 Выставить чек"
3. Выбирает метод оплаты
4. Клиент получает счет в Telegram
5. Клиент нажимает "Оплатить"
6. Вводит данные карты
7. Бот подтверждает платеж (PreCheckoutQuery)
8. Оплата завершается (successful_payment)
9. Клиент и мастер получают уведомления

Сценарий 6: Оставление отзыва клиентом
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Клиент открывает "📅 Мои записи"
2. Видит завершенную запись с кнопкой "⭐ Оставить отзыв"
3. Нажимает "Оставить отзыв"
4. Выбирает оценку от 1 до 5 звезд через кнопки
5. Напишет текстовый отзыв (или пропускает)
6. Отзыв сохраняется в системе
7. Мастер получает уведомление о новом отзыве
8. Средний рейтинг мастера обновляется автоматически

Сценарий 7: Просмотр отзывов
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Для клиентов:
1. Клиент переходит по ссылке мастера
2. Видит список услуг с средним рейтингом мастера
3. Нажимает "⭐ Отзывы" для просмотра всех отзывов
4. Видит список отзывов с оценками и текстом (по 5 на странице)
5. Переходит между страницами через кнопки "◀️ Предыдущая" и "Следующая ▶️"

Для мастеров:
1. Мастер открывает "⚙️ Настройки"
2. Нажимает "⭐ Мои отзывы"
3. Видит все свои отзывы с средним рейтингом (по 5 на странице)
4. Видит детальную информацию: услуга, клиент, дата, оценка, текст отзыва
5. Переходит между страницами через кнопки навигации

Сценарий 8: Мастер оставляет отзыв другому мастеру
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Мастер записывается к другому мастеру через "📝 Записаться к мастеру"
2. После завершения услуги открывает "📝 Записи как клиент"
3. Видит завершенную запись с кнопкой "⭐ Оставить отзыв"
4. Нажимает "Оставить отзыв" и выбирает оценку 1-5 звезд
5. Может добавить текстовый отзыв или оставить только оценку
6. Мастер, оказавший услугу, получает уведомление с пометкой "👨‍💼 Мастер"

Добавление нового функционала
------------------------------

Пример: Добавление новой команды
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Создайте функцию-обработчик в соответствующем модуле handlers
2. Зарегистрируйте обработчик в ``bot/main.py``:

.. code-block:: python

   from bot.handlers import my_module
   application.add_handler(CommandHandler("newcommand", my_module.new_command))

Пример: Добавление новой валидации
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Добавьте функцию в ``bot/utils/validators.py``
2. Используйте в обработчиках:

.. code-block:: python

   from bot.utils.validators import my_validator
   
   if not my_validator(value):
       await update.message.reply_text("Ошибка валидации")
       return

Лучшие практики
---------------

* Всегда используйте ``get_db_from_context()`` для получения сессии БД
* Используйте ``safe_edit_message_text()`` для редактирования сообщений
* Логируйте все важные действия
* Обрабатывайте ошибки с try/except
* Используйте type hints для лучшей читаемости кода
* Следуйте принципам SOLID и KISS
